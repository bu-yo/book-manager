# 藏书管家

一套可直接双击打开的家庭藏书管理网页应用，覆盖原《书目.xlsx》的全部字段与用法，并补上了统计、检索和导入导出。

> 内置数据：从 `书目.xlsx` 的「全部书目」导入的 **172 种 / 260 册**，打开即可看到你自己的藏书。

---

## 一、怎么打开

**最简单**：双击 `index.html`，用 Edge / Chrome 打开即可，不需要安装、不需要联网。

**想在手机上用**：双击 `启动本地服务.bat`（需要已安装 Python），它会起一个本地服务并打开 `http://localhost:8000`；手机连同一个 Wi-Fi，访问 `http://电脑IP:8000` 即可。

## 二、功能对照

| 原表格的能力 | 在本应用里 |
|---|---|
| 13 个字段：序号、书名、作者、出版社、出版时间、类别、标签、语言、译者、册数、获得渠道、获取时间、备注 | 录入表单完整对应，字段名与顺序一致 |
| 「类别 → 标签」二级联动下拉 | 选类别后，标签下拉自动只显示该类别的标签 |
| 词典表：5 类标签、出版社、作者 | 「分类词典」页可视化维护，可增删标签、重命名类别 |
| 5 个按类别拆分的工作表 | 「分类」页 + 书目页的类别筛选（一个视图看全部，不重复存数据） |
| 序号、合计册数 | 序号自动递增；列表底部实时显示「合计 N 册」 |
| 条件格式按类别上色 | 每本书左侧书脊颜色 + 类别色块 |

### 额外增加

- **总览看板**：类型环图、题材 Top8、出版年代、获得渠道、最近录入、6 个关键指标
- **检索与排序**：全文搜索（书名/作者/出版社/标签/备注）、按类别/语言/年代/渠道筛选、点表头排序
- **重复检测**：录入时同名书会提示
- **撤销**：删除后有「撤销」提示，误删可恢复
- **导入导出**：Excel(.xlsx) / CSV / JSON，可与原表格互相替换
- **备份**：完整 JSON 备份（含词典），换设备可整包迁移

## 三、数据存在哪、怎么备份

- 数据保存在**当前浏览器**的 localStorage 里，不上传任何服务器。
- 「数据与备份」页可以：
  - 导出 **Excel**：格式与原 `书目.xlsx` 一致（同样的 13 列表头），可直接替换原文件
  - 导出 **CSV**：给 Excel 或表格工具用
  - 导出 **JSON**：完整备份，含分类词典，换电脑用这个
- 换浏览器、清理站点数据、重装系统都会丢数据 —— **建议每月导出一次 JSON 备份**。
- 「恢复初始数据」会用内置的 172 种书目覆盖当前数据。

## 五、常见问题

**Q：导出的 Excel 用 WPS 打开提示格式问题？**
A：文件是标准 xlsx（ZIP + OOXML），Excel / WPS / Numbers 都能打开。若提示，用 Excel 打开后另存一次即可。

**Q：导入原 `书目.xlsx` 会丢东西吗？**
A：不会。导入时按表头匹配，只取 13 个已知列；「替换」模式会整表替换，「合并」模式按书名+作者去重。

**Q：为什么有的书没有标签？**
A：标签是可选字段，不影响统计。

**Q：能多人一起用吗？**
A：当前是单机版，数据在各自浏览器里。若要多设备共享，可把 JSON 备份放到网盘手动同步，或后续接一个后端。

本版本：已清空初始书籍，仅保留分类词典；并针对手机端进行了布局优化。
